Kyara Intelligence is an AI gateway that speaks the OpenAI API protocol natively. You can connect any OpenAI-compatible SDK, library, or application by updating three settings — your base URL, your API key, and your model ID. Everything else stays exactly the same, giving you instant access to Kyara-hosted models without learning a new interface or installing additional packages.

## Get up and running

<Steps>
  <Step title="Create an API key">
    Sign in to the [Kyara Intelligence dashboard](https://kyara-intelligence.com/dashboard) and generate a new API key. Keep it somewhere safe — you'll pass it as a Bearer token on every request.
  </Step>
  <Step title="Choose a model">
    Browse the [model catalog](https://kyara-intelligence.com/models) and note the model ID you want to use. You'll supply this as the `model` field in your request body.
  </Step>
  <Step title="Point your client at Kyara">
    Update your OpenAI client configuration with the three settings below and fire off a request — no other code changes are needed.

    ```python
    from openai import OpenAI

    client = OpenAI(
        base_url="https://api.kyara-intelligence.com/v1",
        api_key="<YOUR_API_KEY>",
    )

    response = client.chat.completions.create(
        model="<MODEL_ID>",
        messages=[{"role": "user", "content": "Hello!"}],
    )
    print(response.choices[0].message.content)
    ```

    <Tip>
      Any SDK or tool that accepts a custom `base_url` works the same way — TypeScript, cURL, LangChain, and more.
    </Tip>
  </Step>
  <Step title="Connect a frontend app (optional)">
    Want a chat UI without writing code? Follow the [SillyTavern integration guide](/integrations/sillytavern) to connect a fully-featured frontend to Kyara Intelligence in just a few clicks.
  </Step>
</Steps>
